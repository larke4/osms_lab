# ОСМС — лабораторные работы

Репозиторий с двумя лабораторными работами по курсу
«Основы систем мобильной связи» (ОСМС).

## Лаба 1 — сигналы, Фурье, дискретизация

**Файл:** `lab1.py`
**Отчёт:** `report_lab1.pdf`

Сигнал варианта 20: `y(t) = 7·cos(2π·20·t + π/3)`.

Что сделано:
- генерация и визуализация сигнала;
- ручное ДПФ и ОПФ по формулам (1.8) и (1.9) методички
  (без `numpy.fft`);
- амплитудный спектр, восстановление, квантование АЦП
  (3–6 бит, MAE/MSE);
- проверка `max|idft(dft(y)) − y| ≈ 1e-12`;
- синтез мелодий (ноты) как проверка ДПФ на сложном сигнале.

## Лаба 2 — радиопокрытие, бюджеты каналов

**Файл:** `lab2.py`
**Отчёт:** в разработке

Что сделано:
- модели PL: FSPM (2.1–2.2), UMiNLOS (2.3), COST231 Hata (2.4–2.7),
  Walfish-Ikegami (2.8–2.16);
- бюджеты DL/UL (2.19–2.20), MAPL, RxSens (2.17–2.18);
- расчёт радиусов `d_DL`, `d_UL` бинарным поиском по `PL(d)=MAPL`;
- радиус соты `min(d_UL, d_DL)`, число БС на заданной площади;
- интерфейс с полями всех параметров варианта.
