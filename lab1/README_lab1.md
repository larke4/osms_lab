  ЛАБА 1 ОСМС — КРАТКАЯ ТЕОРИЯ
  Вариант 20: y(t) = 7*cos(2*pi*20*t + pi/3)

1. СИГНАЛ
----------------------------------------------------------------
Сигнал — физический процесс, несущий информацию. В радиосвязи это
электромагнитное колебание, которое описывается зависимостью
амплитуды (напряжения) от времени u(t).

Аналоговый сигнал — непрерывный по времени и по амплитуде.
Цифровой сигнал — последовательность чисел (отсчётов), которые
хранятся в памяти устройства.

Наш сигнал:
    y(t) = A*cos(2*pi*f0*t + phi)
    A = 7,  f0 = 20 Гц,  phi = pi/3
    omega = 2*pi*f0 = 125.66 рад/с
    T = 1/f0 = 0.05 с
    y(0) = 7*cos(pi/3) = 3.5


2. АЦП — АНАЛОГО-ЦИФРОВОЕ ПРЕОБРАЗОВАНИЕ
----------------------------------------------------------------
АЦП превращает непрерывный сигнал в цифровой и делает три вещи:

  2.1. Временная дискретизация — берём значения сигнала через
       равные промежутки Ts = 1/Fs. Получаем отсчёты (samples).
  2.2. Квантование по уровню — округляем каждое значение до
       ближайшего из L = 2^b уровней (b — разрядность АЦП).
  2.3. Кодирование — упаковываем номер уровня в b бит и пишем
       в регистры памяти.

Параметры АЦП:
  • разрядность b (число бит на отсчёт);
  • частота дискретизации Fs (сколько отсчётов в секунду);
  • диапазон входного сигнала [Umin, Umax];
  • передаточная характеристика (ступенчатая).

Шаг квантования:  Delta = (Umax - Umin) / (L - 1) = 2A / (2^b - 1).

Ошибка квантования (шум квантования):
  MAE = mean(|q - y|),  MSE = mean((q - y)^2).

Чем больше b, тем меньше шаг и ошибка. При b=3 шаг = 14/7 = 2,
при b=6 шаг = 14/63 ≈ 0.222.


3. ТЕОРЕМА КОТЕЛЬНИКОВА (Найквиста—Шеннона)
----------------------------------------------------------------
Непрерывный сигнал с ограниченным спектром можно точно
восстановить по его отсчётам, если частота дискретизации
не меньше удвоенной максимальной частоты сигнала:

        Fs >= 2 * f_max

Величина 2*f_max называется ПОРОГОМ КОТЕЛЬНИКОВА,
а Fs/2 — ЧАСТОТОЙ КОТЕЛЬНИКОВА (она же частота Найквиста).

Для нашего сигнала:
    f_max = 20 Гц
    порог = 2 * 20 = 40 Гц

Если Fs < 40 Гц — возникает АЛИАСИНГ (наложение спектров):
высокая частота «складывается» в низкую, восстановить сигнал
невозможно. На спектре вместо пика на 20 Гц появится ложный
пик на |Fs - 20|.

В программе кнопки «1x, 2x, 4x, 10x» дают Fs = 40, 80, 160, 400 Гц.
На «1x» Fs ровно на пороге — форма едва восстанавливается.
На «2x» и выше — восстановление корректное.


4. ПРЕОБРАЗОВАНИЕ ФУРЬЕ
----------------------------------------------------------------
Идея Фурье: любой сложный сигнал можно разложить в сумму
простых синусоид с разными частотами, амплитудами и фазами.

Прямое преобразование Фурье (ПФ) переводит сигнал из временной
области в частотную, обратное (ОПФ) — наоборот.

Формулы для дискретного сигнала (методичка, 1.8 и 1.9):

  Прямое ДПФ:
    F(x) = SUM_{n=0}^{N-1} f(n) * exp(-j*2*pi*x*n/N),  x = 0..N-1

  Обратное ДПФ:
    f(n) = (1/N) * SUM_{x=0}^{N-1} F(x) * exp(+j*2*pi*x*n/N)

Обозначения:
  f(n) — отсчёты сигнала во времени (n = 0..N-1);
  F(x) — спектральные коэффициенты (комплексные числа);
  N    — число отсчётов;
  j    — мнимая единица.

Каждый коэффициент F(x) — это комплексное число, у которого:
  |F(x)|   — амплитуда на частоте x*Fs/N;
  arg F(x) — начальная фаза на этой частоте.

Быстрое преобразование Фурье (БПФ, FFT) — это просто ускоренный
алгоритм для вычисления того же самого ДПФ (алгоритм Кули—Тьюки).
Математически результат тот же, но вычисляется за N*log2(N)
операций вместо N^2. В лабе FFT не используется — ДПФ считается
вручную по формуле выше, чтобы была видна сама математика.


5. СПЕКТР
----------------------------------------------------------------
Спектр — представление сигнала по частотам. Строится из ДПФ:

  Односторонний амплитудный спектр:
    A(x) = 2 * |F(x)| / N   для x = 1..N/2-1
    A(0)    = |F(0)| / N     (DC не удваиваем)
    A(N/2)  = |F(N/2)| / N   (бин Котельникова не удваиваем)

  Частоты бинов:
    f(x) = x * Fs / N,  x = 0..N/2

  Разрешение по частоте:
    dF = Fs / N

Для косинусоиды y(t) = A*cos(2*pi*f0*t + phi) в спектре ровно
две линии: на +f0 и -f0, каждая с амплитудой A/2. В одностороннем
спектре видна только +f0 с амплитудой A/2 = 3.5.

Почему на графике «гора», а не «иголка»:
  • конечное N даёт не дельта-функцию, а пик конечной ширины
    (ядро Дирихле);
  • если в окне укладывается не целое число периодов, возникает
    УТЕЧКА СПЕКТРА (spectral leakage) — пик размазывается.

Утечку уменьшают:
  • выбором длительности, кратной 1/f0 (например, D = 0.05 с);
  • оконными функциями (Ханна, Хэмминга) перед ДПФ;
  • увеличением N (больше отсчётов — тоньше бин).


6. ДЕЛЬТА-ФУНКЦИЯ И ДИСКРЕТИЗАЦИЯ
----------------------------------------------------------------
Математически дискретизация — это умножение аналогового сигнала
x(t) на гребёнку дельта-функций:

    p(t) = SUM_{n=-inf}^{+inf} delta(t - n*Ts)

Свойства дельта-функции:
    INT delta(t) dt = 1                (площадь)
    INT x(t)*delta(t-a) dt = x(a)      (фильтрующее свойство)

После умножения:
    x_d[n] = x(t) при t = n*Ts = x(n*Ts)  — отсчёты сигнала.

Спектр гребёнки — тоже гребёнка с шагом Fs. Поэтому после
дискретизации спектр аналогового сигнала повторяется с периодом
Fs (см. рис. 1.6 методички). Если Fs < 2*f_max, эти копии
перекрываются — вот и алиасинг.


7. ЧТО ИМЕННО СДЕЛАНО В ПРОГРАММЕ
----------------------------------------------------------------
